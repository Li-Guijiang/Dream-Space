## 关于这个博客

这个博客使用 **Next.js 16 + React 19 + Tailwind CSS 4** 构建，采用玻璃拟态（Glassmorphism）设计风格。在这里你可以看到我写的技术文章、日常说说、一起聊天的杂谈，还有照片墙和左下角内置的一些实用小工具。
